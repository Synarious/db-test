    How the ratings work

    Each activity direction pairs the corresponding roles, such as giving with receiving. Shared options use the same prompt for both people.

    Both percentages use the pairs scored in the selected mode. Relaxed counts two yes answers or two no answers as compatible. Strict and Standard leave shared boundaries outside the scores.

    Blank ratings and preferences that need more context appear below the scores.

    A hard limit remains a boundary at every setting. Agree on consent together before trying anything.

Troubleshooting

Start over

On the Profiles page, select Clear MyList data and confirm. To clear one rating, choose Left blank for that topic.

Answers do not save

Allow this site to use browser storage. Use the same browser profile and site address when you return to MyList.

Move or restore saved answers

On the Profiles page, choose Export next to a saved profile to download a JSON copy. Select Import backup to open a backup file, or paste a share URL and select Review import. In the review, you can fill blank fields in your active profile or create a new named profile.

Import fills blank fields with compatible values and keeps existing answers and profile details. It skips changed or removed questions, duplicate ratings, and invalid values. Older backups rely on known question IDs. If a question changed meaning or split into two directions, rate the new options separately. If the MyList data saved in your browser is unreadable, importing a JSON backup offers to replace it after confirmation.

Using a screen reader

Use your screen reader’s headings and form controls to navigate. With a keyboard, use Tab to reach Previous, Next, or the section picker at the bottom. Press Enter or Space to open the picker. Use the arrow keys to move between ratings for an option.

Image download fails

Try Download text on the results page or follow the iPhone and iPad download guide.
